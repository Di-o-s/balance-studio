# Balance Studio

Статический веб-сервис для проверки баланса игры. Сделан по кейсу «Balance & Progression Studio» на примере данных нашей стратегии CombatMap (отряды пехоты, танков, артиллерии и т.д.).

Сервер и база данных не нужны: всё работает в браузере, данные хранятся в localStorage.

## Что умеет

| Вкладка | Что делает |
|---|---|
| 1. Импорт | Загрузка CSV и JSON через выбор файла или drag&drop. Разделитель `,` / `;` и BOM от Excel определяются сами. Проверка обязательных колонок, чисел, диапазонов, допустимых значений, дублей ID, лишних ячеек. Можно заменить данные или добавить к текущим. |
| 2. Таблица | Редактор юнитов: правка ячеек, добавление, дублирование и удаление строк (с отменой), сортировка, поиск, подсветка ошибочных ячеек, автосохранение. |
| 3. Урон / TTK | Урон и время до убийства для пары «атакующий → цель» с расчётом по шагам, дуэль в обе стороны, матрица TTK «все против всех» с экспортом. |
| 4. Прогрессия | Степенная или экспоненциальная формула опыта с настраиваемыми коэффициентами, таблица уровней, график, экспорт CSV/JSON. |
| 5. Лут | Таблицы дропа, проверка суммы шансов = 100% по каждой таблице, подсветка ошибок, нормализация, симуляция бросков, экспорт результата проверки. |
| 6. Аудит | Поиск «доминирующих» и «бесполезных» юнитов по силе за единицу цены. |
| 7. Экономика | Симулятор инфляции: источники и стоки ресурса, прогноз на N шагов. |
| 8. Навыки | Визуализатор дерева навыков из JSON, проверка циклов и битых ссылок, подсветка пути и подсчёт стоимости. |
| 9. Ассистент | Отправка агрегированной сводки в DeepSeek API и получение текстового разбора. Баланс автоматически не меняется. |

Плюс: тёмная тема (по системе или вручную), адаптивная вёрстка, горячие клавиши, экспорт всего проекта одним JSON и его восстановление.

## Запуск

**Локально.** Скачать репозиторий и открыть `index.html` в браузере двойным кликом. Сборка не нужна, все библиотеки лежат в папке `lib/`.

Если нужен локальный сервер (например, для ассистента):

```
python -m http.server 8000
```

и открыть http://localhost:8000.

**Онлайн.** Сервис опубликован на GitHub Pages: `https://<логин>.github.io/balance-studio/`.

Как опубликовать свою копию:

1. Создать на GitHub публичный репозиторий `balance-studio` и загрузить в него содержимое папки (или `git push`).
2. В репозитории открыть Settings → Pages.
3. В Source выбрать «Deploy from a branch», ветка `main`, папка `/ (root)`, нажать Save.
4. Через 1-2 минуты сайт будет доступен по адресу выше.

## Формат данных

**Юниты** - обязательные колонки `id, name, hp, attack, defense, cost`.
Необязательные (если нет - берутся значения по умолчанию):

| Колонка | По умолчанию | Смысл |
|---|---|---|
| `attack_speed` | 1 | атак в секунду |
| `crit_chance` | 0 | шанс крита, от 0 до 1 |
| `crit_mult` | 1.5 | множитель крита |
| `damage_type` | melee | `melee`, `explosive` или `bullet` |
| `res_melee`, `res_explosive`, `res_bullet` | 0 | сопротивление: 0.3 = на 30% меньше урона, -0.2 = на 20% больше |

**Лут** - `id, table, item, chance` и необязательная `rarity`. `chance` в процентах, строки с одинаковым `table` образуют одну таблицу дропа.

**JSON** - массив объектов, объект `{"units": [...]}` / `{"loot": [...]}`, файл полного проекта (экспорт «Весь проект») или дерево `{"nodes": [{"id", "name", "cost", "requires": [...]}]}`.

## Формулы

```
урон        = max(атака − защита, 0.1 × атака) × (1 − сопротивление[тип урона]) × множитель
сопротивление ограничено сверху 0.9
средний урон = урон × (1 + шанс_крита × (множитель_крита − 1))
удары        = ⌈HP цели / урон⌉
TTK          = удары / скорость атаки
```

Прогрессия (опыт для перехода с уровня L на L+1):

```
степенная:        XP(L) = base × L^exponent + linear × L
экспоненциальная: XP(L) = base × growth^(L−1) + linear × L
```

Лут: сумма шансов таблицы должна быть 100 ± 0.01.

Аудит: `сила = √(DPS × EHP)`, `ценность = сила / цена`, вердикт по отношению к медиане (по умолчанию > 1.3 - доминирует, < 0.7 - бесполезен).

## Ассистент (DeepSeek)

Нужен свой API-ключ с https://platform.deepseek.com. Ключ вводится на вкладке «Ассистент» и уходит только на `api.deepseek.com`. По желанию его можно запомнить в localStorage этого браузера. В запрос попадает не вся таблица, а сводка: средние статы, вердикты аудита, самые быстрые и медленные пары TTK, проверка лута, параметры прогрессии. Что именно отправится, видно справа от формы.

## Тесты

Формулы и разбор файлов вынесены в чистые функции (`js/formulas.js`, `js/data.js`) и покрыты тестами:

```
node tests/formulas.test.js
```

Нужен только Node.js, зависимостей нет. Ожидаемые числа в тестах посчитаны вручную, расчёт приведён в отчёте.

## Структура

```
index.html          разметка, вкладки, подключение скриптов
css/style.css       стили, светлая и тёмная тема
lib/chart.umd.js    Chart.js 4.4.1 (локальная копия, чтобы работало без интернета)
js/formulas.js      урон, TTK, прогрессия, лут, аудит, экономика, дерево - без DOM
js/data.js          CSV/JSON парсер, схемы данных, валидация - без DOM
js/store.js         состояние и автосохранение в localStorage
js/ui.js            помощники для DOM
js/samples.js       встроенные тестовые наборы
js/modules/*.js     по файлу на вкладку
js/app.js           вкладки, тема, горячие клавиши, экспорт
data/               тестовые CSV и JSON
tests/              тесты формул
```

Модули подключаются обычными `<script>`, а не ES-модулями: так страница открывается прямо из файла, без сервера.
